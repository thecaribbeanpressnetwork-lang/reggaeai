# ReggaeAI

Caribbean-first AI music discovery, creation, licensing and catalogue platform.

This repository contains the ReggaeAI web application. Shot Call Records operates as the release-intelligence layer behind the platform; creator ownership is not transferred by upload or import.

## V1

- Discover / search
- The Riddim Yard
- Persistent player
- Creator accounts and library
- One-link AI-song import pipeline
- Creator upload and rights confirmation
- Buy / licence architecture
- Treblo-first generation adapter
- SEO-first public catalogue
- Provider-independent payments with WiPay as the first production rail

No production credentials belong in this repository.
